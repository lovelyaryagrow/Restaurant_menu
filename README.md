# ***Restaurant Ordering System***



* ##### ***Project Description***



This is a simple Python program for a restaurant ordering system. 

The program displays a menu with different food items and their prices. 

The user can enter an item name, and the program checks whether the item 

is available in the menu.



If the item is available, its price is added to the total order amount. 

The user can also choose whether they want to add another item to the order.



* ##### ***Menu***



| Item   | Price   |

|--------|---------|

| Pizza  | Rs. 100 |

| Pasta  | Rs. 50  |

| Burger | Rs. 35  |

| Salad  | Rs. 80  |

| Coffee | Rs. 65  |



* ##### ***Features***



\- Displays the restaurant menu.

\- Takes the item name from the user.

\- Checks whether the entered item is available.

\- Adds the price of the selected item to the total.

\- Allows the user to add more than one item.

\- Displays the total amount at the end.



* ##### ***Technologies Used***



\- Python

\- Dictionary

\- if-else statements

\- while loop

\- input() function

\- print() function



* ##### ***How to Run***



1\. Make sure Python is installed on your computer.

2\. Open the Python file in IDLE, VS Code, or any Python editor.

3\. Run the program.

4\. Enter the name of the food item when asked.

5\. Choose whether you want to add another item.

6\. The total amount will be displayed at the end.
