# Restaurant Ordering System

## 1. Problem Statement

Restaurants need a simple and efficient way to manage customer orders and calculate the total bill. Manual ordering can lead to mistakes while recording items and calculating prices.

The **Restaurant Ordering System** is a simple Python-based application that allows users to view the available menu, select food items, add multiple items to their order, and calculate the total amount of the order automatically.

The system also checks whether the requested item is available in the menu and displays an appropriate message if the item is not available.

---

## 2. Scope of the Project

The scope of this project is to develop a basic console-based restaurant ordering system using Python.

The system will:

- Display the restaurant menu and prices.
- Allow the user to enter the name of a food item.
- Check whether the selected item is available.
- Add the price of available items to the order total.
- Allow the user to add multiple items to the order.
- Calculate and display the total order amount.
- Display a message when an item is not available.

The project is intended as a basic demonstration of Python concepts such as dictionaries, variables, conditional statements, loops, user input, and formatted output.

The target users of this project are:

---

## 4. High-Level Features

### 4.1 Menu Display
The system displays the available food items along with their prices.

### 4.2 Item Selection
The user can enter the name of the food item they want to order.

### 4.3 Item Availability Check
The system checks whether the entered item exists in the restaurant menu.

### 4.4 Order Management
The user can add more than one item to their order.

### 4.5 Automatic Price Calculation
The system automatically adds the price of each selected item to the total order amount.

### 4.6 Invalid Item Handling
If the user enters an item that is not available, the system displays a message informing them that the item is unavailable.

### 4.7 Total Bill
After the user finishes ordering, the system displays the total amount of all selected items.

## 6. Menu Items

The restaurant menu contains the following items:

| Item | Price |
|------|------:|
| Pizza | Rs. 100 |
| Pasta | Rs. 50 |
| Burger | Rs. 35 |
| Salad | Rs. 80 |
| Coffee | Rs. 65 |

The system accepts both uppercase and lowercase versions of the menu items.

---

## 7. Basic Workflow

1. The program starts and welcomes the user.
2. The restaurant menu is displayed.
3. The user enters the name of an item.
4. The system checks whether the item exists in the menu.
5. If the item is available, its price is added to the order total.
6. The user is asked whether they want to add another item.
7. If the user chooses to continue, another item is requested.
8. This process continues until the user chooses not to add another item.
9. The final total amount is displayed.

---
